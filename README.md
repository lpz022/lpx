# 图书馆座位管理系统

## 完成人
谢秉宏


## 项目简介
本项目是一款基于Web的智能座位管理系统，适用于高校及公共图书馆，实现座位预约、用户与座位管理、传感器模拟、数据存储与实时状态展示等功能，提升图书馆座位管理的智能化与便捷性。

## 主要功能
- 座位预约与实时状态展示
- 用户注册、登录与管理
- 管理员座位与用户管理
- 传感器数据模拟与控制
- 数据以JSON文件存储，轻量易维护

## 使用方法
1. 克隆本仓库到本地：
2. 进入项目目录，安装依赖并启动服务。
3. 通过浏览器访问 `index.html` 体验系统功能。

## 目录结构
- `src/library/public/` 前端页面与脚本
- `src/library/src/` 后端服务与数据处理
- `src/library/data/` 数据存储（JSON文件）
- `src/library/tools/` 传感器模拟工具
